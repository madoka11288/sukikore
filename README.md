# 好き相関図（Suki Correlation Map）

自分の「好き」を星として置き、**なぜ好きか**を書き、共通するタグから見えていなかった相関を見つけるアプリです。
単体の HTML ファイルとして動くので、サーバーを立てなくてもブラウザで開けばそのまま使えます。
さらに、同じ Wi-Fi 内のスマホ・PC と **6桁の数字（部屋コード）** で内容を同期できます。

## 特徴

- **名前 / タグ / 好きな理由 / 色 / 強さ** を持つ「好き」の点（ノード）
- **強さ＝光**：星の大きさ・光量・流れる光の数で表現。強さ5の「好き」は脈動し光条が出る
- **つながり（リンク）**：関係のラベルと強さ 1〜5（線の太さ・流れる光の速さ）
- **タグで絞り込み**：上部のタグチップを複数選択。件数付き
- **検索**：名前・タグ・理由を横断検索（`Ctrl/⌘ + K`）。一致しないノードは減光
- **相関の自動表示**：まだ線を引いていない「共通タグの組み合わせ」をピンクの点線で浮かび上げる
- **編集 / 複製 / 削除**：削除は確認ダイアログ付き（同時に外れるつながりの本数を表示）
- **一覧ビュー**：カードで強さ順に並べ、その場で編集・削除
- **スマホ対応**：詳細パネルが下端シートに変化（スワイプで閉じる）／ピンチズーム／指ドラッグ
- **自動保存**（ブラウザの localStorage）＋ JSON 書き出し・読み込み
- **同じ Wi-Fi での同期**：6桁の部屋コードで複数端末の内容をマージ

## ファイル構成

| ファイル | 役割 |
|---|---|
| `suki-correlation-map.html` | アプリ本体。これ1つだけでも動きます |
| `suki-sync.js` | 同じ Wi-Fi 内で同期するためのサーバー（Node.js 標準機能のみ・依存パッケージなし） |

## 使い方（同期なし）

`suki-correlation-map.html` をブラウザで開くだけです。最初からサンプルの相関図が入っています。
白紙から始めたい場合は「Data → すべて消す」。サンプルに戻すには「Data → サンプルを読み込む」。

## 使い方（同じ Wi-Fi の端末と同期）

1. PC で、この2ファイルを同じフォルダに置き、次を実行します（Node.js 18 以上）。

   ```bash
   node suki-sync.js
   ```

2. ターミナルに **部屋コード（6桁）** と、同じ Wi-Fi の端末用 URL が表示されます。

   ```
   部屋コード ：  434597   ← 他の端末でこの6桁を入力
   この端末        http://localhost:8787
   同じWi-Fiの端末 http://192.168.1.23:8787
   ```

3. PC のブラウザで `http://localhost:8787` を開くと、自動で接続されます（サーバー自身の内容が基準になります）。

4. スマホなど他の端末で `http://192.168.1.23:8787` を開き、左下 **「同期」** から **6桁のコード** を入力して「接続する」。
   そのまま `http://192.168.1.23:8787/?code=434597` のように URL にコードを付けて開くと、入力なしで接続できます。

5. 接続後は、どの端末での追加・編集・削除も、他の端末にほぼ即時に反映されます。
   左下の「同期」ボタンの点が緑なら同期中、接続台数も確認できます。

- ポートを変えたいとき： `PORT=9000 node suki-sync.js`
- HTML を直接開いていて（`file://`）同期したい場合： 「同期」画面の「サーバー」欄に PC のアドレス（例 `192.168.1.23:8787`）を入れて接続します
- データはサーバーには保存されません（起動中のみメモリに保持）。各端末が自分の localStorage に保存し、参加時に内容を送り合うため、サーバーを再起動しても各端末から復旧します

### 同期のしくみ

- 各レコードは `ut`（更新時刻）を持ち、**新しいほうを優先**してマージします
- 削除は「墓標（tomb）」として記録するので、**消したものが復活しません**
- 送受信は Server-Sent Events（`/api/events`）で、変更はその場で他の端末へ配られます
- 部屋コードが一致しないリクエストは 404 で拒否されます
- サーバーが保持するのは「部屋」1つぶんの状態だけです

## データ形式（JSON 書き出し）

```json
{
  "v": 1,
  "nodes": [
    { "id": "abc1234", "name": "深夜のラジオ", "tags": ["ひとり時間", "音"],
      "reason": "誰かと一緒に起きている気分になれる。", "color": "#5FD2FF", "s": 5, "ut": 1759100000000 }
  ],
  "links": [
    { "id": "l000001", "a": "abc1234", "b": "def5678", "label": "夜のひとり時間", "s": 4, "ut": 1759100000000 }
  ],
  "tombs": {}
}
```

`ut` と `tombs` は同期用です。手で書き換える場合は触らなくても動きます。

## 動作環境

- モダンブラウザ（Chrome / Safari / Edge / Firefox の現行版）
- データは localStorage に保存されるため、**同じブラウザ・同じオリジン**で開いたときに引き継がれます
- 同期サーバーは Node.js 18 以上（標準モジュールのみ使用）

## キーボード操作

| キー | 動作 |
|---|---|
| `Ctrl / ⌘ + K` | 検索を開く |
| `F` | 全体を表示（Fit） |
| `C` | 選択中の点を中央に |
| `+` / `-` | 拡大 / 縮小 |
| `Esc` | 閉じる / 選択解除 |
| ダブルクリック | その位置に新しい「好き」を追加 |
